# Security Policy

## Supported versions

Security fixes are intended for the current `main` branch. Older commits and deployed instances may contain known limitations; do not assume they receive security updates.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities, credentials, personal information, or exploit details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If private reporting is unavailable, contact the repository owner privately with a concise description of the affected component, potential impact, and safe reproduction steps.

Allow reasonable time for investigation and remediation before publicly disclosing a vulnerability. Do not test against systems or data that you do not own or have explicit permission to assess.

## Project security limitations

This is an academic project and is not currently suitable for handling real emergency reports or sensitive personal information. In particular, the backend's authentication, authorization, and report-privacy controls are still being improved. See the open security work in [issue #9](https://github.com/lomeshpawar/Disaster-Emergency-Alert-System/issues/9).

Do not submit real personal, medical, location, or emergency data to public demo environments.
